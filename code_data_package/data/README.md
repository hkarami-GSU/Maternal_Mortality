# Data

`raw/` is for original WHO/UN MMEIG input files used by the analysis workflows.

`processed/` is for cleaned country-year datasets used by the modelling code.

The current organization keeps the MMR and maternal-deaths workflow copies in separate subfolders to preserve provenance and avoid silently merging duplicate filenames.

No private or individual-level data are used in this study.

Users should cite the original WHO/UN MMEIG source when using these data or derived outputs.
